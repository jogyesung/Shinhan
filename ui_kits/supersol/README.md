# superSOL UI Kit

A high-fidelity recreation of the **superSOL** (슈퍼쏠) mobile app — Shinhan Financial Group's all-in-one super-app. Reference screens come from the New 슈퍼SOL planning deck (`pptx_extract/media/image9.jpeg`, `image12.jpeg`).

## Files
- `index.html` — interactive demo with 3 click-thru screens (Home → Move-Stocks promo → Stock detail)
- `Phone.jsx` — iOS frame wrapper with status bar + bottom nav
- `Home.jsx` — feed of asset / consumption / stock / insurance cards
- `MoveStocksPromo.jsx` — full-screen contextual nudge ("Move stocks to top?")
- `Stock.jsx` — stock holdings list view
- `components.jsx` — shared bits (StatusBar, BottomNav, Card, Button, Avatar)

Recreation, not production code. Korean copy is kept verbatim.
